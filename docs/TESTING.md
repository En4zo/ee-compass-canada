# 验证记录与验收边界

## 自动测试

`npm test` 运行 53 项测试：

| 类别                  | 数量 | 验证内容                                                                                |
| --------------------- | ---: | --------------------------------------------------------------------------------------- |
| CRS 规则              |   23 | 手工按官方表格相加的案例、年龄边界、配偶状态、语言门槛、技能转移、省提名、法语和封顶    |
| IRCC 解析与同步       |   13 | 445 条快照记录、字母编号、重复编号、空数据、异常数值、未来日期、网络失败、重复导入      |
| HTTP 权限与来源       |    5 | 匿名写入、跨域写入、管理员入口、Cron 密钥、误导来源域名                                 |
| PostgreSQL RLS 与事务 |   12 | 执行真实迁移、不同角色读写、伪造作者、编辑/删除他人内容、提权、隐藏、回复继承、批次回滚 |

CRS 默认演示案例：29 岁、无配偶、本科、第一语言四项 CLB 9、加拿大工作 1 年、其他因素为零。按 IRCC 表计算：

- 核心：110 + 120 + 124 + 40 = **394**。
- 学历技能转移：语言组合 25 + 加拿大经验组合 13 = **38**。
- 总分：**432**。

这些期望值独立写入测试，并非用被测函数生成。尚未把所有输入排列与 IRCC 在线计算器逐一比对；评分测试不是申请资格鉴定。

PGlite 测试使用真正的 PostgreSQL 执行 RLS 和 SQL，但在本地模拟 `auth.uid()` 与角色。它验证 SQL 行为，不替代 Supabase 托管 Auth、PostgREST、邮件或 Cookie 的端到端验收。数据库每次在内存中新建，不连接云服务。
